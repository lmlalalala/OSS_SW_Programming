## Repository

이 저장소에서 수업 과제를 주차별로 지속적으로 관리하고 있습니다.

## 시작하기

```bash
git clone https://github.com/lmlalalala/OSS_SW_Programming.git
cd OSS_SW_Programming
```

문서는 Markdown으로 읽을 수 있습니다. `dashboard/index.html`은 브라우저에서 열어 확인합니다.
`scripts/`에는 기존 DORA 지표 및 주간 보고서 스크립트가 있고, `.github/`에는 협업 템플릿과 자동화 설정이 있습니다.
